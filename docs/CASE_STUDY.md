# Case Study — LinkedIn URL Enrichment

## Problem
Sales/research teams often have contact + company lists but missing profile links.
Manual lookup is slow.

## Solution
A structured enrichment pipeline that:
- builds search queries consistently,
- extracts candidate LinkedIn profile URLs,
- writes enriched output table for downstream CRM usage.

## Outcome
- repeatable enrichment process
- API + batch options
- clear hit-rate metric for quality monitoring
